# Spec Delta

## ADDED Requirements

### Requirement: Header brand logo returns to the workflow home
The system SHALL make the left-side MoveEasy brand logo a navigation control that returns the user to the first moving-request page while preserving the active request data.

#### Scenario: Return home from a later workflow stage
- **WHEN** the user activates the MoveEasy logo from a workflow stage or inquiry history
- **THEN** the first moving-request page is displayed and the active request data remains available
